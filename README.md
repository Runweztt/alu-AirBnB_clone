# AirBnB Clone - The Console

This project is the first stage of the AirBnB clone project.

It implements a command interpreter for managing AirBnB objects and provides serialization and deserialization of objects using JSON file storage.

## Command Interpreter

The command interpreter allows users to create, display, update, delete, and list AirBnB objects.

## How to Start

Run:

./console.py

## Interactive Mode

Example:

$ ./console.py
(hbnb) help
(hbnb) quit

## Non-Interactive Mode

Example:

$ echo "help" | ./console.py

## Testing

Run all unit tests with:

python3 -m unittest discover tests
